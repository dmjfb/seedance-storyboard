# 小说转视频分镜提示词

先分析小说全文及角色、场景、物品素材库，再逐段生成符合 Seedance 模板的电影化分镜提示词。支持素材名称 `@` 绑定、角色声线锁定、跨段剧情与画面连续性、缺失素材提示，以及根据用户反馈持续修订。

这是一个 Codex Skill，生成文字分镜提示词，不直接生成或上传视频。

## 安装

将本仓库完整下载或克隆到个人 skills 目录，文件夹名为 `seedance-storyboard`，确保目录内直接包含 `SKILL.md`、`agents/` 和 `references/`。

默认目录为 `~/.codex/skills/seedance-storyboard`；如果设置了 `CODEX_HOME`，使用其下的 `skills/seedance-storyboard`。

## 使用流程

### 1. 先分析全文和素材

调用 `$seedance-storyboard`，提供：

- 小说全文或文本文件路径。
- 场景库 `locations.json`。
- 角色库 `characters.json`。
- 物品库 `items.json`。

三个素材库分别支持 `locations`、`characters`、`items` 数组，也可以提供对应类型的顶层数组或明确的固定名称清单。素材名称使用 `name`，别名 `alias` 和描述 `description` 辅助匹配；素材 ID 用于区分重名条目。

示例：

> 使用 $seedance-storyboard，先分析我提供的小说全文和场景、角色、物品素材库。分析完毕后等待我逐段发送文案，不要直接生成全文分镜。

### 2. 逐段生成

分析完成后，逐段发送需要处理的文案。Skill 直接在对话中输出该段分镜，自动承接已生成的节号、人物站位、情绪、场景和道具归属。

- 默认每节 12–15 秒、最多 8 镜；一个片段可拆成多节。
- 素材清单使用完整素材名进行 `名称@名称` 绑定，声线使用 `角色名@角色名音色`。
- 多个素材匹配时，选择最符合当前剧情及人物形态的已有素材。
- 缺少必要素材时，在分镜正文后单独列出“缺失素材”，便于补充。
- 未提供下一段或明确授权范围时，不自动从全文继续生成。

### 3. 修改和续接

直接说明哪一节、哪个镜头需要修改。局部修改会完整重发受影响的小节，保留其他节编号；当前项目的纠正会用于后续输出。

项目分析及承接记录保存在当前项目的 `work/seedance-storyboard/` 下，不写入 skill 安装目录，也不修改原始小说或素材库。

## 文件结构

```text
seedance-storyboard/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── Seedance-2.0-多参视频提示词v1.0_角场物音@绑定功能.txt
```

固定模板随 skill 内置，保持原文。小说、素材库、媒体文件和项目运行记录不包含在本仓库中。
